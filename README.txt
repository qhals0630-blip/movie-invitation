업데이트 방법
1. GitHub의 movie-invitation 저장소로 이동
2. 기존 index.html 클릭
3. 오른쪽 위 휴지통(Delete this file)으로 삭제 후 Commit changes
4. Add file > Upload files에서 이 폴더의 새 index.html 업로드
5. Commit changes
6. 1~3분 뒤 기존 주소 새로고침

주소:
https://qhals0630-blip.github.io/movie-invitation/
